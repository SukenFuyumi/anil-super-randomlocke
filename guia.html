⬇️ Descargar AnilSync 🌐 Crear mi web (copiar plantilla)

AnilSync es el programita que sube tu partida a la web automáticamente. El botón azul te lo descarga al instante.

¿Cómo se reparten los roles? Solo UNA persona (el organizador) usa GitHub y crea la web + las "llaves" una vez. Cada jugador NO necesita cuenta de GitHub: solo descarga AnilSync y pega la llave que le pasa el organizador. ¡Nada más!
Solo el organizador · una vez

Parte 1 — Crear la web del grupo

Necesitas una cuenta de GitHub (gratis). Créala en github.com si no tienes.

1
Pulsa este botón para copiar la plantilla. Ponle un nombre (ej. mi-randomlocke), déjalo en Public y pulsa Create repository.
2
Enciende la web: en tu copia ve a Settings → Pages. En Source elige Deploy from a branch, rama main, carpeta / (root) y pulsa Save. En 1–2 min aparece tu dirección: tu-usuario.github.io/mi-randomlocke.
3
Pon los datos de tu grupo: abre el archivo data/config.json, pulsa el lápiz ✏️ y cambia el título y la lista de jugadores (un id único por persona). Pulsa Commit changes.
Ver ejemplo de jugadores 
"players": [
  { "id": "ash",  "name": "Ash",  "avatar": "assets/avatars/red.png" },
  { "id": "gary", "name": "Gary", "avatar": "assets/avatars/blue.png" }
]
4
Crea una llave (token) para cada jugador y pásasela. Entra a este enlace → Generate new token:
  • Token name: el nombre del jugador (ej. anilsync-ash).
  • Repository access → Only select repositories → tu repo del grupo.
  • Permissions → Contents → Read and write.
  • Generate token → copia el código (empieza con github_pat_…) y dáselo a ese jugador.
Repite para cada jugador. (Si quieres lo más simple, puedes crear una sola llave y dársela a todos — pero una por jugador es más seguro y puedes revocarlas por separado.)
🔒 Las llaves son como contraseñas de tu repo. Pásalas en privado; si una se filtra, bórrala desde el mismo enlace.
Cada jugador · una vez

Parte 2 — Conecta tu partida

1
Descarga AnilSync con el botón azul de arriba (o aquí). Ponlo en una carpeta cualquiera.
2
Pídele al organizador tu llave (token) — un código que empieza con github_pat_…. No necesitas cuenta de GitHub: el organizador te la genera y te la pasa.
🔒 Guárdala en privado: solo va en tu archivo local.
3
Junto al AnilSync.exe crea un archivo config.json con esto (cambia lo resaltado): 
{
  "playerId": "ash",              // tu id de la lista
  "saveFolder": "",
  "saveSlot": "ask",
  "github": {
    "owner": "tu-usuario",       // dueño del repo del grupo
    "repo": "mi-randomlocke",     // nombre del repo
    "branch": "main",
    "token": "github_pat_LA_LLAVE_QUE_TE_DIERON",
    "pathTemplate": "data/players/{id}.json"
  },
  "watch": true,
  "dryRun": false
}
4
Doble clic en AnilSync.exe. Si te pregunta, elige tu ranura de partida. Deja la ventana abierta mientras juegas: cada vez que guardes en el juego, tu progreso sube solo. 🎉

¿Algo no funciona?

  • La web da error 404: espera unos minutos tras encender Pages; revisa rama main y carpeta / (root).
  • AnilSync dice error 403 (permisos): la llave (token) no tiene Contents: Read and write o no apunta a ese repo, o escribiste mal owner/repo. Pídele al organizador que te regenere la llave.
  • No sube nada: tu playerId debe existir en la lista de jugadores, y el juego debe guardar en la partida correcta.
  • No aparece un jugador: falta su entrada en players de data/config.json.
